## 三、缺陷清单

### D-01（已修复）侧边栏分组的折叠逻辑写反

| 项 | 内容 |
| --- | --- |
| 严重度 | 中（用户可见的功能失效） |
| 现象 | 点击「当前目录」/「最近打开」标题，第一次点无任何变化，第二次点反而收起；且收起后 `aria-expanded="true"`，屏幕阅读器读到的状态和实际相反 |
| 根因 | `setupSidebar()` 里把「取反」写成了两次同向：`collapsed = aria-expanded === "false"` 之后，`setAttribute(aria-expanded, collapsed)` 与 `list.hidden = collapsed` 用的是同一个值，导致属性与可见性永远相反 |
| 修复 | `mdpad/src/main.ts:819-833` 改为先读当前展开态，再 `setAttribute(!expanded)` + `list.hidden = expanded` |
| 验证 | 第 4 区「分组可折叠/展开」由 FAIL 转 PASS（收起后 `#dir-list.hidden === true`，再点恢复 `false`） |

### D-02（登记，不修）菜单栏的剪切/复制不随选区置灰

| 项 | 内容 |
| --- | --- |
| 严重度 | 低 |
| 现象 | 编辑器的右键菜单在无选区时会把「剪切」「复制」置灰，但标题栏「编辑」下拉里这两项始终可点；点下去只给一句状态栏提示「请先选中要复制的内容」 |
| 根因 | 下拉菜单在 `buildMenus()` 里一次性构建（`main.ts:1277` 调用 `menuEntryNode(item)` 时没有传 disabled），状态不会随选区刷新；右键菜单是每次弹出前重建（`main.ts:1327-1328`），所以能正确置灰 |
| 影响 | 不会误操作，只是视觉上不区分可用性；要让下拉也置灰，需要在 `openMenu()` 时重刷禁用态 |
| 处置 | 记录为已知差异，测试用例按当前行为断言 |

## 四、测试脚本自身的问题（非产品缺陷）

首轮 5 项 FAIL 中有 4 项是断言写错，已修正后复跑：

| 断言 | 错在哪 | 修正 |
| --- | --- | --- |
| 各级标题数量 | alpha 文档里 `> # 引用里的标题` 也是 h1，DOM 里 h1 实际 2 个 | 期望改为 `[2,1,1,1,1,1]` |
| 状态栏统计 | 用 `re.sub(r"\d+","N")` 把「7 个标题」也替换了 | 只替换前两个数字 |
| 最近打开含 alpha | 启动时通过会话恢复载入的文件不写「最近打开」，只有 `loadFile()` 才写 | 期望改为 `["beta.md"]` |
| 剩余标签 | `Ctrl+N` 建的两个草稿各占一个标签，实际剩 3 个 | 期望改为三元素 |

另外两处偶发失败，都是脚本的时序/焦点问题，已在脚本里做了兜底：

- 另存为后用固定 `sleep(2.4)` 就断言落盘，赶在异步写盘前面 → 改成轮询文件出现 + 轮询标签改名。
- `SendInput` 发的 `Ctrl+Shift+S` 偶发丢失首个组合键 → 增加「没弹出对话框就重试」，并按 PID 而不是标题定位窗口，避免打到残留实例。
- 打开对话框的文件名框会保留上次内容，直接输入会拼成非法路径 → 输入前先 `Ctrl+A` 全选。

## 五、未覆盖范围

| 项 | 原因 |
| --- | --- |
| 从资源管理器拖入文件 | 拖放由 WebView2 的 DnD 事件投递，`SendInput` 无法构造 OLE 拖放，需要人工验证 |
| 非 UTF-8（GBK/Shift_JIS）编码 | 代码只认 UTF-8，本就不支持；属已知限制 |
| 超长文档（>100 KB）性能 | 需求里没有性能门槛，且预览未做虚拟化 |
| 多窗口 / 多实例 | 应用是单窗口模型 |
| PDF / HTML 导出 | 功能未实现 |
| 后台标签的外部文件变更 | 文件监听只挂在活动标签上（已知限制），切回后台标签不会重新读盘 |
